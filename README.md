# sentinel-agent
Autonomous Goal Agent is an AI agent built on a perceive → reason → act loop. Given a high-level objective, it observes its environment, breaks the goal into sub-tasks, picks and uses tools to carry them out, checks the results, and changes its plan when something fails. It keeps going until the goal is reached, with little human input.  Key features:  🔍 Perception: gathers and interprets state from the environment (APIs, files, web, sensors) 🧠 Reasoning & planning: breaks goals down into actionable steps using an LLM-based planner ⚙️ Action execution: calls tools and APIs on its own to carry out each step 💾 Memory: short-term context plus long-term memory of past actions and outcomes 🔁 Self-reflection: evaluates results, recovers from errors, and re-plans when needed 🛡️ Guardrails: safety checks and optional human-in-the-loop approval for critical actions
